# AI使用说明

## AI辅助内容

本项目由Codex根据用户提出的目标、项目架构、验收标准、约束等。AI完成架构方案复用与改写、绝大部分代码、合成资料、模型与工具适配、自动化测试、真实模型调用、20组混合测试集、错误排查、修复补丁和文档整理。

AI用于分析实际Trace、定位漏答和校验问题，并执行回归。真实API输出与离线脚本明确分开；没有将Mock结果写成模型决策，也没有删除失败后冒充全部通过。测试数量及限制按实际记录描述，未声称完成生产验证。

## 个人修改及验证

提出混合问题及多轮续答要求；亲自通过CLI测试年假、VPN、报销和资料外问题；更换模型并反复测试反馈结果；指出会话未衔接、报销子问题漏答、范围判断偏保守、文档主题遗漏和命名不规范等问题，并据实际输出审阅修复效果。

这些属于提交者的测试设计、问题发现、需求调整和结果验证。依据反馈形成的代码补丁、自动化回归及文档改写由Codex辅助完成。
